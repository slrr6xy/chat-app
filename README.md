# チャットアプリ

リアルタイムでメッセージをやりとりできるグループチャットアプリです。

## 機能

- ルームの作成・入室・退出
- パスワード付きルーム対応
- 自分と他人のメッセージをスタイルで区別
- 自分の名前は非表示（他人のみ表示）
- シンプルで見やすい UI

## 使用技術

- Node.js
- Express
- Socket.io
- HTML/CSS/JavaScript

## 起動方法

```bash
git clone https://github.com/slrr6xy/chat-app.git
cd chat-app
npm install
node server.js
```
ブラウザでhttp://localhost:3000 を開くと利用できます。
